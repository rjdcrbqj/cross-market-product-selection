# 通用多产品跨市场选品 Skill v1.3.0

v1.3.0 把经过实际项目验证的多 Agent 协作机制封装为通用能力。它仍以目标产品 ID 隔离需求、外观、功能、价格、证据和排名，不固定为吹风机，也不写死 Agent 数量。

## 新增

- 按目标产品、平台/站点和阶段动态拆分商品发现、视觉功能核验、市场数据、供应商与报价核验等工作包。
- 支持真实子 Agent 分派、依赖等待、独占输出路径、原始返回保存、检查点恢复和失败重试留痕。
- 增加独立复核角色；复核者不得是首次研究者，须覆盖拟进入严格结果的全部记录及边界、冲突和异常记录。
- 只有主协调者可以写最终 Excel；合并时按目标产品重新去重、计算价格基准、评分和排名，冲突证据保留为 `CONFLICTED`。
- 新增协同运行清单格式与 `scripts/validate_orchestration.py`，检查冻结需求、目标覆盖、依赖循环、提前开工、输出冲突、复核独立性及合并就绪状态。

## 行为变化

- 用户明确要求多 Agent 或协同选品时，Skill 会读取多 Agent 编排协议并按当前环境实际可用的并发位执行，不再只用角色文字模拟协作。
- Agent 数量由任务规模和环境能力决定；一个角色可分批处理多个目标，不要求固定七个 Agent。
- 工具不可用时明确采用单 Agent 降级，不把单 Agent 分角色写作称为独立复核或多 Agent 已运行。
- 安装 Skill 不修改全局或项目 Agent 配置，不绑定原项目路径、品类、模型或账号。

## 边界

运行清单校验只能证明任务包结构和文件就绪，不能证明网页证据真实、图片外观相似、供应商已经验厂或检索覆盖充分。正式选品仍必须实际访问目标平台、保存原始证据、逐图核验并运行 Excel 校验；严格结果不足时不得凑数。

## 兼容性

- 保持 Amazon、1688、联合模式、固定九表、需求基线、逐图核验和 4:4:2 评分规则不变。
- 单 Agent 任务仍按原流程执行，不强制创建子 Agent。
- 历史版本 v1.2.1、v1.2.0、v1.1.1、v1.1.0 和 v1.0.0 仍可按标签安装。

## 安装

```text
请使用 $skill-installer 安装这个 Skill：
https://github.com/rjdcrbqj/cross-market-product-selection/tree/v1.3.0/skills/cross-market-product-selection
```

安装后重启或重新加载 Codex，并在新任务中显式输入 `$cross-market-product-selection`。需要多 Agent 时，在需求中增加“请使用 Skill 内置的多 Agent 协同编排”。

## 验证

- 完整自动化回归：138 项通过。
- Skill 结构检查：仓库副本和本机安装副本均通过；18 个正式 Skill 文件一致。
- 独立离线试跑：实际运行两个研究 Agent 和一个独立复核 Agent，覆盖两个非吹风机目标、6 条合成来源和 5 条目标商品组合；跨产品数据未串用，缺证记录未进入严格结果。
- 计划及合并清单校验均通过。独立裁决为附条件通过且仅覆盖合成离线中间证据交接；它不是 Amazon、1688 实时检索或真实供应商核验。
