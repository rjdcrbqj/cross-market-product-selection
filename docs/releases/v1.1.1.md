# v1.1.1 发布说明

v1.1.1 是选品结果质量加固版本，修复候选表混入失败项、候选图片缺失、链接不能直接打开，以及凭标题或泛化关键词误判外观相似的问题。Skill 仍是通用品类工作流，不写死任何单一产品。

## 修复

- `亚马逊候选`、`1688候选`和`货源匹配`只允许`严格合格`或`待核验`；`已淘汰`只能进入`淘汰记录`。
- 候选表和严格结果中的商品行都必须嵌入与本行商品/变体对应的实际主图，同时保留主图 URL；空白、数字`0`/`1`、图片 ID、微小图和全透明占位图均不合格。
- 商品链接、主图链接、供应商主页和证据链接必须同时保留有效 URL 文本与目标一致的 XLSX hyperlink，确保单击即可打开。
- 任务书将外观、外观排除项、功能和禁用功能分别编号；严格合格必须在`外观逐项核验`和`功能逐项核验`中逐条给出结论与实际图片/详情证据。
- 标题或关键词只能发现候选，不能证明外观通过；看不到关键结构时转入待核验，图片明确不符时转入已淘汰。
- Amazon 目标售价允许偏差与 1688 目标成本允许偏差分开记录；任务说明目标是唯一价格基准，行内目标必须一致，校验器用任务目标与原始价格重新计算价格分和严格行是否越界。
- `不通过：原因`、`不合格（原因）`等描述性失败不能混入候选；“通过”与证据文字矛盾也不能通过逐项核验。
- 联合模式逐项证据必须同时标明 Amazon 与 1688 两侧；`亚马逊候选`和`1688候选`中的严格合格行也会独立重算 4:4:2 评分。

## 其他校验加固

- 新增候选状态、描述性失败、候选图片有效性、候选链接、数字占位、逐项证据矛盾、任务目标一致性、候选评分和严格价格范围检查。
- 工作簿模板新增`外观逐项核验`和`功能逐项核验`列，并按工作表限制可选状态。
- 仍保持中文工作表、中文表头、固定七表和销量 40% + 价格 40% + 评价 20% 的平台评分规则。
- 严格合格不足目标数量时如实交付，不补旧款、不补异类商品、不凑 Top-N。

## 兼容性

v1.1.1 的模板与校验规则比 v1.1.0 更严格。旧工作簿可以继续查看，但缺少候选嵌入图、XLSX hyperlink、编号任务书或逐项核验列时不会通过新版校验；这是为了阻止不可靠结果继续被标记为可交付。

历史版本仍可安装：

## 安装

在 Codex 新任务中复制：

```text
请使用 $skill-installer 安装这个 Skill：
https://github.com/rjdcrbqj/cross-market-product-selection/tree/v1.1.1/skills/cross-market-product-selection
```

安装后重启或重新加载 Codex，再用`$cross-market-product-selection`显式调用。

## 验证

交付 Excel 前运行`scripts/validate_workbook.py`；只有返回零问题，并且实际渲染检查确认候选图片与链接正确，才能交付。
