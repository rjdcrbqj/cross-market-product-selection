# 通用跨市场选品与货源匹配 Skill v1.1.0

## 新增

- 将工作流升级为通用品类流程：每次任务先确认参考图片、外观特点、功能、排除项、目标价格、价格允许偏差、数量和站点，不把单一产品的规则写进核心 Skill。
- 平台产品评分固定为销量 40%、价格 40%、评价 20%，不作为联合最终配对分。`scripts/scoring.py` 拒绝 NaN/Infinity，使用价格绝对偏差计算对称的价格相似分；Amazon 比较目标售价，1688 比较与目标采购数量匹配的目标成本。
- 新增中文七表模板 `assets/通用选品数据库模板.xlsx`、工作簿校验器 `scripts/validate_workbook.py`，以及中文界面与使用说明。
- 严格结果支持嵌入实际商品主图，并保留有效 `http(s)` 主图链接与来源链接供追溯。

## 行为变化

- 实际主图、功能、商品身份、价格范围和供应商资质先作为硬门槛；标题、关键词、搜索缩略图和推测不能替代证据。
- 只对严格合格且销量、价格、评价证据齐全的候选评分。缺失或冲突的证据转入待核验，不以 0 或代理指标补足，也不凑 Top-N。
- 欧洲 Amazon 综合榜会跨站去重以避免重复占位，同时保留分站观测；分国家榜则分站独立排名。
- 1688 严格 ODM 工厂必须有供应商主页、生产能力证据和 ODM/OEM/定制正向证据。SerpApi 优先级低于 Sorftime，只能补充 Amazon 搜索和商品详情，不能核验 1688，也不能由评论数、BSR 或搜索位置推断销量。
- 固定七表不再用于推断模式；模式取自任务说明并与逐行模式交叉校验。严格结果从原始销量、价格、星级重算，销量只比较同口径严格行，业务身份去重不受记录 ID 遮蔽。
- 联合模式分开呈现市场机会、供应能力和匹配质量；未确认最终配对公式与三类权重时，最终配对得分和排名保持空白。

## 兼容性

- 保持 Skill 名称、Amazon/1688/联合三种模式和现有安装路径不变。
- 旧工作簿可以作为输入读取；v1.1.0 的新输出采用中文七表、中文表头和中文状态。
- `v1.0.0` 仍可安装，用于复现旧版本行为。
- 当前 artifact-tool 导出未能持久化冻结前三行，因此 v1.1.0 模板不预设冻结窗格。数据、公式、图片和校验不受影响；如需冻结，可在 Excel 中手动冻结前三行。发布说明不将模板表述为“已冻结”。

## 安装

安装固定 v1.1.0：

```text
请使用 $skill-installer 安装这个 Skill：
https://github.com/rjdcrbqj/cross-market-product-selection/tree/v1.1.0/skills/cross-market-product-selection
```

安装后重启或重新加载 Codex，并在新任务中显式输入 `$cross-market-product-selection`。历史版 `v1.0.0` 安装链接为：

```text
https://github.com/rjdcrbqj/cross-market-product-selection/tree/v1.0.0/skills/cross-market-product-selection
```

最新开发版使用：

```text
https://github.com/rjdcrbqj/cross-market-product-selection/tree/main/skills/cross-market-product-selection
```

## 验证

- `scripts/scoring.py` 覆盖销量标准化、价格对称性、评价换算和固定 4:4:2 总分。
- `scripts/validate_workbook.py` 校验精确表头、任务/行模式、全部适用硬门槛、嵌图与 URL、原始值重算、业务去重、连续排名、供应商主页、生产能力与 ODM/OEM/定制证据，并保留公式文本和缓存值。
- `tests/` 覆盖评分、Skill/文档结构、模板、工作簿校验器及从真实提交模板生成的 Amazon、1688、联合合成集成工作簿。合成夹具只验证产品路径，不伪装成平台实时结果。
- `tools/maintain_selection_template.mjs` 是受版本控制的模板维护脚本，仅用 `@oai/artifact-tool` 重建二进制资产，不是 Skill 运行依赖。
