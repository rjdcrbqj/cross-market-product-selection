# 通用多产品跨市场选品 Skill v1.2.1

v1.2.1 修复实际使用中“工作簿自洽但偏离用户要求”的问题，补全从真实参考图发现相似商品、逐图核验到供应商主体补查的执行链。它仍是多产品通用 Skill，不把任何单一品类的外形或价格写死。

## 改进

- 保留多产品通用结构，不硬编码某型号、形状或统一价格。
- 对标要求不得退化成泛品类，核心功能不得降为可选，价格偏差与采购量不得自行假定为已确认。
- 正式工作簿校验增加独立检索前需求基线，逐产品比对冻结字段；旧文件可用 `--audit-only` 诊断，不视为交付验收。
- 固化真实参考种子、找相似/图搜、深页增量、逐图筛选、同店/主体补查、断点和预算边界；不把前两页/五页当默认结束。
- 待核验表同样检查已知价格越界及明确失败门槛；普通单图也检查重复严格视觉结论。
- 允许有真实图片/商品链接但主体尚待查证的商品线索，必须标明缺口和补查动作；不将其计作严格工厂。
- 区分搜索参考价与确认 SKU 档位价，区分商品、具名供应商、严格 ODM 主体及可评分结果；销量榜与综合分榜分别呈现。
- 随附九表模板补齐搜索参考价、报价口径、补查动作，以及待核验表应保留的实际价格/门槛字段，避免新规则没有地方填写。

## 边界

检索深度和证据质量不是 Agent 数量或 Excel 行数。程序校验只验证可机器检查的字段与需求快照，不能证明视觉语义、搜索穷尽或用户确认的真实性；仍需实际复核原始请求和图片。原始用户文件仅作本地只读回归，不进入发布包。

## 兼容性

- 保持 Amazon、1688 和联合三种模式以及固定九表基础结构；旧七表仍可用 `--audit-only` 做内部一致性诊断。
- 正式结果改用 `python scripts/validate_workbook.py 输出.xlsx --requirements requirements.json`；不带需求基线的含业务数据工作簿不再视为正式交付通过。
- 待核验商品可在供应商主体未知时保留真实图片和稳定商品链接，但必须写清缺口与补查动作，且不能计为严格工厂。
- 历史版本 v1.2.0、v1.1.1、v1.1.0 和 v1.0.0 仍可按标签安装。

## 安装

```text
请使用 $skill-installer 安装这个 Skill：
https://github.com/rjdcrbqj/cross-market-product-selection/tree/v1.2.1/skills/cross-market-product-selection
```

安装后重启或重新加载 Codex，并在新任务中显式输入 `$cross-market-product-selection`。
