# 通用多产品跨市场选品 Skill v1.2.0

v1.2.0 将原有通用选品能力升级为真正的多产品 Agent Skill：同一任务可同时处理多个目标产品，每个产品的参考图、外观、功能、价格、证据、去重、评分、排名和 Top-N 全程隔离。Skill 仍适用于不同品类，不写死折叠吹风机或任何单一产品规则。

## 新增

- 新增唯一`目标产品ID`合同；一行一个目标产品，可同时录入产品 A、产品 B 及更多目标产品。
- 新增`目标产品`和`价格基准`工作表，新输出由七表升级为固定九表。
- 新增严格多视图模式：候选至少提供同商品或同变体的主图与关键结构/状态图，每张不小于 240×240。
- 新增结构化视觉证据，逐项记录候选可见事实、对标参考和关键差异，不能仅凭标题、关键词或模板句判定外观通过。
- 新增可复制的`多产品提示词模板.md`，要求先输出各目标产品冻结合同，经确认后再批量检索。

## 行为变化

- 检索、去重、销量标准化、价格计算、评分、排名和 Top-N 均按`目标产品ID`独立执行，避免不同品类或价位互相污染。
- Amazon 每个目标产品使用至少 5 个去重后的同类合格样本重算`Amazon同类均价`；严格价格下限取同类均价与目标售价允许下限的较高值，明显低价商品不得进入严格结果。
- 1688 严格记录必须绑定 SKU、采购档位、MOQ、阶梯价和目标成本价格带；已知价格越界直接淘汰。
- 每个目标产品分别计算严格结果数量和排名；严格合格不足目标数量时如实少于 Top-N，不跨产品借用候选、不凑数。
- 候选表仍只保留`严格合格`或`待核验`；已淘汰记录只进入`淘汰记录`。候选图片、URL hyperlink 和供应商证据继续执行 v1.1.1 的质量门槛。

## 兼容性

- 新任务使用固定九表多产品结构；v1.1.1 的旧七表单产品工作簿保留只读兼容路径，但不再作为新输出模板。
- 新校验器要求业务行引用已定义的`目标产品ID`，并检查分产品价格样本、严格多视图、价格边界与排名隔离。缺少这些字段的旧工作簿可能无法通过新版交付校验。
- 历史版本仍可安装：[v1.1.1](https://github.com/rjdcrbqj/cross-market-product-selection/tree/v1.1.1/skills/cross-market-product-selection)、[v1.1.0](https://github.com/rjdcrbqj/cross-market-product-selection/tree/v1.1.0/skills/cross-market-product-selection) 和 [v1.0.0](https://github.com/rjdcrbqj/cross-market-product-selection/tree/v1.0.0/skills/cross-market-product-selection)。

## 安装

在 Codex 新任务中复制：

```text
请使用 $skill-installer 安装这个 Skill：
https://github.com/rjdcrbqj/cross-market-product-selection/tree/v1.2.0/skills/cross-market-product-selection
```

安装后重启或重新加载 Codex，再用`$cross-market-product-selection`显式调用。

## 验证

发布前运行完整自动化测试、Skill 快速校验和空白九表模板校验。交付实际选品 Excel 时，还必须运行`scripts/validate_workbook.py`并目视检查候选图片、结构视图与链接；只有零问题且实际内容可辨识时才能交付。
