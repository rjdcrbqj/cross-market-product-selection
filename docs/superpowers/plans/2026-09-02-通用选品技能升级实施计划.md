# 通用选品技能升级实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将 `cross-market-product-selection` 升级为中文优先、适用于任意品类、能先确认外观/功能/价格硬门槛、按 4:4:2 评分并生成嵌入商品主图 Excel 的通用选品 Skill。

**Architecture:** 保留一个与具体品类无关的核心工作流，每次任务动态生成中文《选品任务书》，再通过 Amazon、1688 或联合模式完成检索与证据核验。评分和工作簿校验由无第三方依赖的 Python 脚本提供确定性行为；Excel 模板使用 Codex 自带 `@oai/artifact-tool` 重建并进行视觉验证。

**Tech Stack:** Markdown、YAML、Python 3 标准库、OOXML/ZIP、`unittest`、`@oai/artifact-tool`、Git、GitHub CLI。

**Spec:** `docs/superpowers/specs/2026-09-02-通用选品技能升级设计.md`

## Global Constraints

- 核心 Skill 不得写死吹风机、P10 或任何单一产品的外观规则；产品专属条件只能存在于当次任务书或可选品类配置中。
- 默认使用中文编写 Skill 正文、参考说明、Excel 工作表、表头、状态、结论和 GitHub 文档；固定文件名、ASIN、SKU、URL、API、FBA、Sorftime、SerpApi 等技术标识保留原文。
- 外观、功能、商品身份、价格允许范围和供应商资质属于硬门槛，必须先于评分。
- 实际主图是外观最终证据；需要外观核验但主图未嵌入 Excel 的行不能进入“严格合格”。
- 价格分采用双向接近原则：`MAX(0, 100 × (1 − |实际价格 − 目标价格| ÷ 目标价格))`。
- 总评分固定为：`销量标准分 × 40% + 价格相似分 × 40% + 评价标准分 × 20%`。
- 严格结果按总评分降序；同分依次比较销量标准分、评价数量、价格相似分。
- 缺少销量、价格或评价证据的行默认进入“待核验”，不计算总评分。
- Amazon 欧洲综合榜必须去除跨站点重复占位；分国家榜保留各站点观测。
- 1688 严格供应商必须有供应商主页、生产能力及 ODM/OEM/定制证据，不能只凭商品链接、店名带“厂”或平台普通标签判断。
- 不得为了满足 Top-N 或供应商数量而凑数；缺失值不得无依据写成 `0`。
- 工作簿创作与修改使用 `@oai/artifact-tool`，不得使用 `openpyxl`；读取与确定性 OOXML 校验可使用 Python 标准库。
- 每个任务完成测试后独立提交，发布前保持工作区干净并运行全量验证。

```python
from collections.abc import Sequence


def _round(value: float) -> float:
    return round(float(value), 2)


def sales_scores(values: Sequence[float]) -> list[float]:
    if not values:
        return []
    normalized = [float(value) for value in values]
    if any(value < 0 for value in normalized):
        raise ValueError("销量不能为负数")
    minimum = min(normalized)
    maximum = max(normalized)
    if maximum == minimum:
        return [100.0 for _ in normalized]
    return [_round(100 * (value - minimum) / (maximum - minimum)) for value in normalized]


def price_similarity_score(actual: float, target: float) -> float:
    actual_value = float(actual)
    target_value = float(target)
    if actual_value < 0:
        raise ValueError("实际价格不能为负数")
    if target_value <= 0:
        raise ValueError("目标价格必须大于零")
    score = 100 * (1 - abs(actual_value - target_value) / target_value)
    return _round(max(0, score))


def rating_score(rating: float, maximum: float = 5.0) -> float:
    rating_value = float(rating)
    maximum_value = float(maximum)
    if maximum_value <= 0 or rating_value < 0 or rating_value > maximum_value:
        raise ValueError("评价分数超出平台评分范围")
    return _round(rating_value / maximum_value * 100)


def total_score(sales: float, price: float, rating: float) -> float:
    values = [float(sales), float(price), float(rating)]
    if any(value < 0 or value > 100 for value in values):
        raise ValueError("子分必须位于 0 到 100 之间")
    return _round(values[0] * 0.4 + values[1] * 0.4 + values[2] * 0.2)
```

- [ ] **Step 4: 实现 OOXML 提取**

使用 Python 标准库 `zipfile.ZipFile` 和 `xml.etree.ElementTree`：

1. 从 `xl/workbook.xml` 与关系文件解析工作表名称和路径；
2. 同时支持共享字符串、内联字符串、数字和公式缓存值；
3. 自动找到包含“状态”的实际表头行，不把标题行或说明行当表头；
4. 通过工作表 drawing 关系、`xdr:from/xdr:row`、图片关系和 `xl/media/` 判断具体 Excel 行是否有嵌入图片；
5. 将每个数据行转换为 `RowRecord`；
6. CLI 接收一个 `.xlsx` 路径，以 UTF-8 JSON 输出 `{"ok": bool, "issues": [...]}`，有错误时退出码为 1。

命令行入口：

```python
def main(argv: list[str] | None = None) -> int:
    parser = argparse.ArgumentParser(description="校验通用选品 Excel 工作簿")
    parser.add_argument("workbook", type=Path)
    args = parser.parse_args(argv)
    model = extract_workbook_model(args.workbook)
    issues = validate_workbook_model(model)
    print(json.dumps({"ok": not issues, "issues": [issue.__dict__ for issue in issues]}, ensure_ascii=False, indent=2))
    return 0 if not issues else 1
```
