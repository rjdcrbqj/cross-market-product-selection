# 多产品视觉与价格加固实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将跨市场选品 Skill 升级为一次任务可处理多个目标产品、且能阻止宽泛外观证据和过低价格进入候选的通用 Agent Skill。

**Architecture:** 新增`目标产品`和`价格基准`两张结构化审计表，所有业务行以`目标产品ID`关联。校验器按目标产品隔离参考合同、价格样本、评分组、去重和排名；严格视觉模式额外验证双图分辨率和结构化逐项证据。

**Tech Stack:** Python 3 标准库校验器与 unittest；JavaScript `@oai/artifact-tool` 模板维护器；XLSX/OOXML。

**Spec:** `docs/superpowers/specs/2026-09-04-多产品视觉价格加固设计.md`

## Global Constraints

- 通用规则不得包含吹风机专用部件或姿态名称。
- Amazon 同类均价、价格边界、销量组、去重、排名与 Top-N 必须按目标产品ID隔离。
- 1688 成本区间必须同时有下限和上限，严格行必须绑定 SKU、采购档位、MOQ 与阶梯价。
- 严格多视图模式要求两张至少 240×240 的真实商品图和结构化可见事实。
- 旧七表单产品模型保留兼容；新模板使用九表结构。
- 不新增第三方依赖，不推送、不发布。
