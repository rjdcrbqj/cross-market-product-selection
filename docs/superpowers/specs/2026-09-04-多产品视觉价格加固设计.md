# 多产品视觉与价格加固设计

## 目标

把现有单一任务书升级为可在一次任务中处理多个目标产品的通用选品 Agent Skill。每个目标产品独立绑定参考图、必需视图、外观与功能清单、目标售价/成本、价格容差、同类价格样本池、Top-N 和结果状态；任何计算和证据不得跨目标产品污染。

## 工作簿结构

在原七表基础上增加两张必要的审计表：

1. `目标产品`：一行一个目标产品，以`目标产品ID`为主键，保存该产品的已确认参考、视觉模式、硬门槛、价格和数量规则。
2. `价格基准`：一行一个可审计价格样本，保存目标产品ID、跨站产品组ID、纳入状态、标准价格、来源和时间，用于独立重算 Amazon 同类均价。

所有候选、匹配、严格、待核验和淘汰记录增加`目标产品ID`。评分组、业务去重、供应商去重、排名和 Top-N 均先按目标产品ID隔离，再应用原有平台维度。

## 视觉对标合同

每个目标产品选择`普通单图`或`严格多视图`：

- 普通单图保留现有主图要求。
- 严格多视图要求至少两个编号必需视图、两个参考图链接，以及候选侧主图和对比/结构图；两张嵌图均须至少 240×240 且对应同一商品/变体。
- 严格多视图的每个外观编号必须使用`候选可见事实=…；对标参考=…；关键差异=…`结构。只写图片已下载、标题含关键词或详情记录存在不能通过。
- 同一目标产品下，多条严格结果不得复用完全相同的外观核验文本。

具体产品的 N/1/7 姿态、T 形、颜色、材质等只写入该目标产品行，不写死在通用 Skill 或校验器中。

## 价格合同

Amazon 每个目标产品先对通过产品身份、外观和功能门槛的去重整机建立`价格基准`样本池。纳入样本必须有正数标准价格、标准币种、跨站产品组ID、来源链接和获取时间。样本数不得低于该目标产品确认的最低样本数，默认 5。

校验器独立重算算术均价，并要求目标产品表记录值一致。Amazon 严格价格区间为：

- 下限：`MAX(同类合格池算术均价, 目标售价 × (1 - 价格允许偏差))`
- 上限：`目标售价 × (1 + 价格允许偏差)`

1688 按每个目标产品独立执行对称成本区间：

- 下限：`目标成本 × (1 - 价格允许偏差)`
- 上限：`目标成本 × (1 + 价格允许偏差)`

已知实际价格超出区间属于明确失败，即使该行写成待核验也必须移入淘汰记录。1688 严格行还必须绑定 SKU、采购数量档位、MOQ 和阶梯价，防止配件价、样品价、定金价或虚假起订价冒充整机成本。

## 结果与命名

- 每个目标产品最多输出其确认的严格结果数；不足时如实少于 Top-N。
- 只有严格合格记录计入产品或 ODM 工厂数量；待核验线索不得写成已确认候选或工厂。
- 文件名和交付说明必须分别披露各目标产品的严格、待核验、淘汰数量。

## 兼容与边界

旧七表单产品工作簿保留只读兼容路径；新模板和新生成任务使用九表、多产品结构。当前修改不引入视觉模型或新依赖，不发布或推送远端版本。
