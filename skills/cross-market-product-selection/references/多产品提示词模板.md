# 多产品选品提示词模板

将方括号内容替换为本次任务的真实信息。产品 A、产品 B 是两个独立目标；需要更多产品时按同一结构继续添加。

```text
$cross-market-product-selection

你要执行的是一次“多目标产品”的跨市场选品任务，不是用一套外观或价格条件筛所有产品。

全局任务：
- 模式：[Amazon / 1688 / 联合]
- 市场与站点：[例如 Amazon 德国、法国、意大利、西班牙；1688 中国大陆]
- 销量口径：[例如近30天可追溯销量]
- 评价口径：[星级、评价数、变体合并规则]
- 交付：一个中文 Excel，固定九表；严格合格不足不凑数。

产品A：
- 目标产品ID：[A-001]
- 目标产品名称/用途：[...]
- 参考商品链接或附件：[...]
- 视觉对标模式：[普通单图 / 严格多视图]
- 必需视图：[视图1=整体主视图；视图2=关键结构或状态图]
- 外观必须特点：[外观1=…；外观2=…]
- 允许变化：[...]
- 外观排除项：[排除1=…；无则写“无”]
- 必须功能：[功能1=…；功能2=…]
- 可选功能：[...]
- 排除功能：[禁用功能1=…；无则写“无”]
- Amazon 目标售价/币种/允许偏差：[...]
- 1688 目标成本/币种/允许偏差：[...]
- 1688 采购数量档位：[...]
- 目标严格合格数量：[...]

产品B：
- 目标产品ID：[B-001]
- 目标产品名称/用途：[...]
- 参考商品链接或附件：[...]
- 视觉对标模式：[普通单图 / 严格多视图]
- 必需视图：[视图1=整体主视图；视图2=关键结构或状态图]
- 外观必须特点：[外观1=…；外观2=…]
- 允许变化：[...]
- 外观排除项：[排除1=…；无则写“无”]
- 必须功能：[功能1=…；功能2=…]
- 可选功能：[...]
- 排除功能：[禁用功能1=…；无则写“无”]
- Amazon 目标售价/币种/允许偏差：[...]
- 1688 目标成本/币种/允许偏差：[...]
- 1688 采购数量档位：[...]
- 目标严格合格数量：[...]

执行要求：
1. 必须先输出冻结合同：一行一个目标产品，展示目标产品ID、参考图、必需视图、外观/功能/排除编号、两侧价格与 Top-N。只询问会改变检索或资格判断的缺失信息；未确认的产品不得进入批量检索。
2. 必须按目标产品ID完全隔离参考图、检索词、均价样本、外观/功能证据、价格边界、去重、评分、排名和结果数量。不得复制上一个产品的证据或用同一组泛词通过多个产品。
3. 先检查参考图的真实外形和功能资料，不得仅根据型号名或用户简称推断。严格多视图产品的每个候选至少嵌入主图与关键结构/状态图，两图原始像素都不小于 240×240，并保留可单击原链接。
4. 外观逐项证据必须对每个“外观N/排除N”分别写：“候选可见事实=…；对标参考=…；关键差异=…”。标题、关键词、“整体相似”或跨行重复模板句不能通过。
5. Amazon 每个目标产品至少用 5 个去重后、本体/外观/功能均合格的同类样本重算算术均价。候选严格价格下限=max(合格同类均价,目标售价×(1-允许偏差))，上限=目标售价×(1+允许偏差)。已知价格低于下限或高于上限时直接淘汰，不得放入待核验。
6. 1688 每个目标产品独立使用目标成本×(1±允许偏差)的上下限。已知价格越界时直接淘汰；严格候选必须同时绑定具体 SKU/规格、采购数量档位、MOQ、对应阶梯价、供应商主页、生产能力和 ODM/OEM/定制证据。
7. 只对严格合格行在同一目标产品ID内按销量40%、价格40%、评价20%评分和排名。严格数量不足不凑数；给出每个目标产品的要求数、严格数、待核验数、淘汰数和限制。
8. 使用固定九表：任务说明、目标产品、价格基准、亚马逊候选、1688候选、货源匹配、严格结果、待核验、淘汰记录。所有业务行必须填写目标产品ID，图片嵌入 Excel，全部 URL 同时保留文本和可单击 hyperlink。
9. 交付前必须运行 Skill 自带的工作簿校验器。任何价格、外观证据、图片、身份、去重、评分、排名或表结构错误都不得交付。
```

## 使用要点

- 目标产品越多，越要保持每个 ID 的证据、均价和排名相互独立。
- 如果用户只给型号没有参考图，先补图或可核验商品页，不使用模型常识自行补完外观合同。
- 已知价格越界是明确失败，不是“待核验”。待核验只用于价格、视图、功能或身份尚缺可靠证据且没有明确失败的情况。
