# 证据质量

证据必须与所主张的字段、稳定商品身份、变体和取得时间对应。每个字段记录原始值、标准值、来源类型、来源 URL、ASIN/1688 商品 ID/SKU、取得时间、置信度和冲突说明。

## 证据类别与用途

| 证据类别 | 可证明的内容 | 使用限制 |
| --- | --- | --- |
| 实际详情页主图 | 实物外观、颜色、形态、可见套装与商品主体 | 外观硬门槛优先使用；必须对应同一商品和变体 |
| 商品规格 | 尺寸、材料、参数、功能声明、变体信息 | 来自商品详情页或可追溯的结构化商品数据 |
| 供应商主体页 | 店铺或企业身份、经营资质、定制和服务能力 | 不可用商品图片 ID、昵称或搜索摘要替代主体名称 |
| 平台分析数据 | 销量、评价、价格、排名或市场指标 | 记录工具、站点、周期和取得时间；只用于其实际覆盖字段 |
| 搜索摘要 | 候选发现、关键词和初步线索 | 不作为外观、功能、身份或价格的最终证明 |

标题和关键词可用于发现候选，但不能作为外观最终证据；生成图片、图片预览或推测也不能替代实际详情页主图。

## 有序来源层级

按字段选择最接近该字段的一手证据，优先级依次为：

1. 对应稳定商品 ID 和变体的当前商品详情页（主图、规格、实际价格和功能）；
2. 对应供应商的官方主体页或供应商详情页（主体、资质、定制与服务能力）；
3. 绑定同一稳定 ID 的平台结构化商品或分析数据（销量、评价和可覆盖的市场指标）；
4. 可追溯到同一 ID 的可靠次级来源；
5. 搜索摘要或视觉预览，仅用于发现线索。

推断不得证明任何硬门槛。低层级证据不能因方便而覆盖更高层级的字段证据。

## 置信度、冲突与状态

详情页中与稳定身份和准确变体绑定的当前字段通常为高置信度；已绑定稳定身份但不是字段权威来源的结构化结果为中等；搜索摘要、预览或变体不清的内容为低；没有可靠来源为缺失。来源冲突时先核对身份、站点、变体、币种、单位和时间，再按字段权威性裁决：商品外观、规格、功能和实际价格优先商品详情页，供应商主体和资质优先供应商主页，销量和评价优先其对应的平台分析数据。保留双方原始值、裁决依据和取得时间；不能裁决时将受影响硬门槛放入待核验。

- 严格合格：所有硬门槛有足够可靠的通过证据。
- 待核验：没有可靠的失败证据，但存在缺失、低置信度或冲突。
- 已淘汰：可靠证据显示至少一个硬门槛不通过；记录失败门槛和来源。

空白表示未知，不能默认为 0、否、无库存或失败。不得把评价数当销量、搜索排名当份额、标价当成交价、标题当外观证明，或由推测补足材料、功能和供应商信息。
