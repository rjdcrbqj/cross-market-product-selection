# Excel输出规范

以 `assets/通用选品数据库模板.xlsx` 为起点（如存在），并保留工作簿结构。使用中文工作表、中文表头和中文状态；技术标识如 ASIN、SKU、URL 可保持原文。

## 工作表与状态

固定七表：任务说明、亚马逊候选、1688候选、货源匹配、严格结果、待核验、淘汰记录。两端联动使用全部七表；单平台模式仍保留七表结构和表名，不适用的候选或匹配表保持为空且结构有效，不新增替代表以免产生八表歧义。状态只能使用“严格合格”“待核验”“已淘汰”，并将三类记录分离：严格结果只含严格合格，待核验写明缺失或下一步，淘汰记录写明已验证失败门槛和来源。

## 表格、链接和排序

每个数据区建立可筛选表格；一行对应一个稳定商品、报价或匹配对。中文表头应覆盖稳定 ID、商品名称、商品链接、主图链接、证据来源、取得时间、原始值、标准值、硬门槛、状态、原因、各项评分和总评分。商品、供应商和证据 URL 必须保留为具有 host 的有效 http/https URL 文本供追溯；v1.1.0 不要求独立 XLSX hyperlink 对象。严格结果按总分降序排序，同分依次比较销量得分、评价数量、价格得分、稳定商品/配对 ID。最后一项仅作纯确定性兜底，不是新评分权重。保留原始值与标准值，ID 以文本保存，避免科学计数法。

## 图片与公式

需要外观核验时，严格合格行必须将实际主图嵌入 Excel，并在独立列保留主图链接；每张实际主图必须与同一行的商品 ID 和变体一一对应，图片锚定同一行、保持比例和统一缩略尺寸。不得以生成图、占位图或链接代替要求嵌入的实际主图。联合模式需分别嵌入并审计 Amazon 侧与 1688 侧图片，使每侧图片各自对应同一行的稳定 ID、变体和主图链接。

评分应保留可检查的原始值、标准分、权重、加权分和总分公式。空值按确认的缺失规则处理，公式不得静默把未知当作 0，也不得出现 `#REF!`、`#DIV/0!`、`#VALUE!` 或损坏的外部链接。

## 导出后检查

导出后运行 `scripts/validate_workbook.py`，并实际打开或渲染检查工作簿。确认固定七表及中文表头、可筛选表格、具有 host 的有效 http/https URL 文本、嵌入图片及主图链接、总分降序、三态分离、公式和空白值均符合要求；逐行检查孤立图片、跨行图片，以及筛选、隐藏或调整行高后图片仍与对应单元格绑定。当前 artifact-tool 导出未能持久化冻结前三行，因此 v1.1.0 模板不预设冻结窗格；数据、公式、图片和校验不受影响，可在 Excel 中手动冻结。若工作簿引擎无法保留嵌入图片，必须在交付中明确披露，且不得将受影响行标为严格合格。
