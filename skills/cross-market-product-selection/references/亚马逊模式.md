# 亚马逊模式

用于核验特定站点商品的市场机会。先读 [需求确认与评分](需求确认与评分.md) 和 [证据质量](证据质量.md)，为每个字段记录来源、时间、冲突和结论。

## 数据源与检索

按字段选择最强可用来源：已配置且可用的 Sorftime 优先；Sorftime 未配置、不可用或缺少字段时，Amazon 搜索和商品详情可按 [SerpApi 亚马逊备用方案](SerpApi亚马逊备用方案.md) 补充；之后才是授权浏览器中的 Amazon 精确商品页、用户提供数据或其他能绑定同站点 ASIN 的可靠来源。

检索矩阵覆盖核心词、同义词、形态词、功能词、排除词、类目/竞品路径和目标站点。逐条记录关键词、页码或深度、返回数量、时间和停止原因；搜索卡只用于发现，须回到精确商品详情核验硬门槛。

## 身份、变体与去重

同一站点按“**站点 + ASIN + 变体**”去重：稳定变体 ID 或 SKU 优先；没有时以可复核的规范化属性组合识别变体。价格、销量、评价、BSR、搜索位置和其他市场指标只是带来源与时间的观测，**观测不得作为身份依据**，多次观测应追加到同一候选的观测台账，不得拆分候选。标题或图片相似也不能自行合并。保留规范 URL、站点、ASIN、所选变体/SKU 或属性组合、检索路径和时间。

欧洲综合榜**分站观测必须保留**，以便审计各站的价格和信号。先建立跨站产品组：优先使用 GTIN/EAN/UPC；其次使用品牌 + 型号 + 稳定变体属性。缺少稳定证据时，不能只凭标题或相似图片自动合并，必须进入人工核验。任务书须在检索前声明综合榜使用代表记录还是聚合口径；不可比站点的指标不得直接相加。为防止**跨站点重复占位**，最终同一产品组只能占一个名额，分站明细仍保留；分国家榜则按各国家/地区站点分别去重、分别排名，不互相挤占名额。

## 硬门槛与评分

评分前依次核验：商品主体不是配件/替换件/补充装/支架/保护套或不相容套装；精确站点、ASIN、变体和价格上下文一致；功能详情和关键规格有证据；实际主图属于该 ASIN 与变体且通过外观、颜色、套装和商品身份核验；实际价格在任务书目标售价范围内；标题、主图、变体、详情和属性无未解决冲突。

实际主图、功能详情、产品身份和目标售价范围全部通过后才评分。主图不可用、模糊或冲突为待核验；有可靠失败证据为已淘汰。原始搜索噪声只能留在候选/淘汰表，不能进入严格结果或排序。

至少保留 ASIN、站点、变体、标题、URL、主图 URL 与观察说明、功能/规格证据、实际价格和币种、评分字段、来源、时间、置信度及冲突说明。销量、收入、竞争或趋势估计必须标示来源和周期；没有可靠来源时留空。仅严格合格且销量、实际价格、评价星级完整无冲突的行可评分。缺少可靠销量不得把排名、评价数量或代理量臆算为销量，应转为待核验且不计算总评分；不足目标数量时如实交付。
