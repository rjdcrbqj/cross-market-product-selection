# 1688模式

用于筛选可追溯的商品和供应商。先读 [需求确认与评分](需求确认与评分.md) 与 [证据质量](证据质量.md)，每项供应商事实都必须对应来源页面和取得时间。

## 数据源与检索路径

优先使用已配置且可用的 1688 专用数据或工作流，其后为授权浏览器中的精确商品详情和**供应商主页**、用户提供的链接/导出/截图，以及绑定精确商品 ID 的其他可信 1688 来源。SerpApi 不能作为 1688 商品详情或供应商事实的核验来源；网页摘要最多帮助发现链接。

检索矩阵必须记录关键词（含同义、材质、形态、工艺、用途、定制和排除词）、以图搜款/相似款、同店商品和供应商主页四类扩展路径。对每条路径记录已尝试、深度、不可用或跳过原因；单一关键词页不代表完整覆盖。

## 双重身份与去重

商品记录按稳定商品 ID 或规范商品 URL 去重；供应商记录按稳定供应商主体 ID 或可核验的供应商主体分别去重。不同供应商的相似标题商品保持不同报价；同一供应商的不同商品链接也不能仅因店名相同而合并。保留商品 ID、SKU/变体、规范 URL、图片、发现路径和时间；供应商保留主体名称（可得时）、主体 ID、供应商主页 URL 与证据链接。

## 商品与供应商硬门槛

先核验商品主体、精确详情、规格/材质/工艺/功能、SKU 价格和 MOQ、实际图片及与任务书一致性；标题和详情冲突时以详情证据为准并记录冲突。阶梯价必须同时记录对应采购数量、SKU 条件和 MOQ；只有与目标采购数量/MOQ 相匹配的价格才能用于成本判断，不能把最低档价格当作通用单价。

任务书要求严格 ODM 工厂时，供应商必须同时具备：可打开且可识别主体的供应商主页；来自主页或权威来源的生产/制造能力；ODM、OEM 或定制能力的明确证据；指向通过商品硬门槛的合格商品链接。店名含“厂”、平台普通标签、年限或未经核验口头描述，均不足以证明严格 ODM 资格。任一项明确不符即已淘汰；缺失、打不开或冲突则待核验，不可因销量、标签或低价转为严格合格。

保留商品 ID、商品/变体 URL、主图、规格、价格区间、数量阶梯、MOQ、样品/打样、定制、交期；以及供应商主体、供应商主页、制造和 ODM/OEM/定制证据、来源、时间、置信度和冲突。仅商品和必要供应商硬门槛都通过的行进入严格结果和排序；未覆盖以图搜款、相似款、同店商品或供应商主页时须披露限制。
