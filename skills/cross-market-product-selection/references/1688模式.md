# 1688模式

用于筛选可追溯的商品和供应商。先读 [需求确认与评分](需求确认与评分.md) 与 [证据质量](证据质量.md)，每项供应商事实都必须对应来源页面和取得时间。

## 数据源与检索路径

优先使用已配置且可用的 1688 专用数据或工作流，其后为授权浏览器中的精确商品详情和**供应商主页**、用户提供的链接/导出/截图，以及绑定精确商品 ID 的其他可信 1688 来源。SerpApi 不能作为 1688 商品详情或供应商事实的核验来源；网页摘要最多帮助发现链接。

检索矩阵必须记录关键词（含同义、材质、形态、工艺、用途、定制和排除词）、以图搜款/相似款、同店商品和供应商主页四类扩展路径。对每条路径记录已尝试、深度、不可用或跳过原因；单一关键词页不代表完整覆盖。关键词只发现候选，必须以同一商品/SKU 的实际主图和详情图逐项比对任务书外观编号；标题或关键词不得作为外观通过证据。

## 双重身份与去重

商品记录按稳定商品 ID 或规范商品 URL 去重；供应商记录按稳定供应商主体 ID 或可核验的供应商主体分别去重。不同供应商的相似标题商品保持不同报价；同一供应商的不同商品链接也不能仅因店名相同而合并。保留商品 ID、SKU/变体、规范 URL、图片、发现路径和时间；供应商保留主体名称（可得时）、主体 ID、供应商主页 URL 与证据链接。

## 商品与供应商硬门槛

先核验商品主体、精确详情、规格/材质/工艺/功能、SKU 价格和 MOQ、实际图片及与任务书一致性；逐项填写`外观逐项核验`和`功能逐项核验`。看不到关键结构、图片无法绑定同一商品/SKU 或详情证据不完整时转入待核验，图片明确不符时转入已淘汰。标题和详情冲突时以详情证据为准并记录冲突。阶梯价必须同时记录对应采购数量、SKU 条件和 MOQ；只有与目标采购数量/MOQ 相匹配的价格才能用于成本判断，不能把最低档价格当作通用单价，并须按任务书 1688 目标成本允许偏差重新核验。

任务书要求严格 ODM 工厂时，供应商必须同时具备：可打开且可识别主体的供应商主页；绑定同一供应商主体并写明生产线、设备、工艺、车间或产能等具体事实的生产/制造能力证据；明确写出 ODM、OEM、开模、打样、贴牌、来图、结构改造或语义等价能力的定制证据；指向通过商品硬门槛的合格商品链接。店名含“厂”、只有商品链接、贸易标签、平台普通标签、年限、泛化宣传、单独“支持”或“支持颜色选择”，均不足以证明严格 ODM 资格。任一项明确不符即已淘汰；缺失、打不开或冲突则待核验，不可因销量、标签或低价转为严格合格。

保留商品 ID、商品/变体 URL、主图 URL、实际嵌入主图、规格、价格区间、数量阶梯、MOQ、样品/打样、定制、交期；以及供应商主体、供应商主页、制造和 ODM/OEM/定制证据、来源、时间、置信度和冲突。1688候选中的严格合格和待核验行均须嵌入对应实际商品主图；商品、主图、供应商主页和证据 URL 都要保留有效 URL 文本并成为单击即可打开的超链接，不能用`1`、店铺昵称或图片 ID 代替。已淘汰只能进入淘汰记录。仅商品和必要供应商硬门槛都通过的行进入严格结果和排序；未覆盖以图搜款、相似款、同店商品或供应商主页时须披露限制。
